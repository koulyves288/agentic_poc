## 🧠 Talking to the AI Agent

To address the AI agent (and trigger an LLM response), prefix your chat message with an `@` symbol. Examples:

```
@Summarize the recent conversation.
@Help me draft a quest plan for Frodo.
```

Messages without the `@` are treated as regular human chat and will NOT be sent to the AI.

Tip: Start with `@` only when you really need AI assistance to keep things fast and focused.

## Welcome screen

To modify the welcome screen, edit the `chainlit.md` file at the root of your project. If you do not want a welcome screen, just leave this file empty.
