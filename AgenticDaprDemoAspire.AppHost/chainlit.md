## 🧠 Talking to the AI Agent

To prompt the AI agent (invoke an LLM response), prefix your message with `@`.

Examples:

```
@Explain Gandalf's last action.
@Generate a tactical plan for Legolas.
```

If you omit `@`, your message stays in the human chat and the AI won't respond. Use this to separate social conversation from directed AI queries.

Pro tip: Only use `@` when needed to reduce latency and noise.

## Welcome screen

To modify the welcome screen, edit the `chainlit.md` file at the root of your project. If you do not want a welcome screen, just leave this file empty.
